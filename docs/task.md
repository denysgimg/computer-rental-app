# Постановка завдання

## Тема, автор і група

- **Тема:** Вебзастосунок обліку прокату комп'ютерів
- **Автор:** Попадюк Денис
- **Група:** ІС-23-01
- **Керівник:** Ковальчук В. Я.

## Призначення програми

Програма автоматизує роботу пункту прокату комп'ютерів: облік техніки, бронювання на період, видача та повернення.

## Користувач і задача

- **Хто користуватиметься:** працівник пункту прокату.
- **Яку задачу допомагає виконувати:** вести облік комп'ютерів, швидко знаходити вільну техніку, бронювати, видавати й приймати її назад без накладок за датами.

## Обраний рівень складності

Достатній (7–9 балів).

## Основні функції

1. Додавання, перегляд, редагування та видалення комп'ютерів.
2. Збереження даних у `db.json`.
3. Перевірка правильності введення.
4. Пошук за назвою.
5. Сортування та фільтрування за типом і статусом.
6. Основна операція: бронювання комп'ютера на період із перевіркою доступності.
7. Видача та повернення комп'ютера.

Реєстрація, вхід і ролі користувачів до обсягу не входять.

## Дані, які зберігатимуться

Файл `db.json` містить три колекції.

| Колекція | Поля |
|---|---|
| `computers` | id, name, type, cpu, ram, status |
| `clients` | id, name, phone |
| `bookings` | id, computerId, clientId, startDate, endDate, status |

Значення `status` комп'ютера: `available` (вільний), `booked` (заброньований), `rented` (виданий). Значення `status` бронювання: `booked`, `rented`, `returned`.

Усі дані навчальні й вигадані.

## Важлива перевірка даних і правило роботи

- Дата завершення бронювання не може бути раніше за дату початку.
- Комп'ютер не можна забронювати на період, який перетинається з наявним активним бронюванням цього комп'ютера. У такому разі програма показує повідомлення, а дані не змінюються.

## Технології

HTML, CSS, JavaScript; Live Server для запуску вебсторінок; json-server для доступу до `db.json`; Git.
