## Призначення

Вебзастосунок для працівника пункту прокату комп'ютерів. Він допомагає вести облік комп'ютерів, бронювати їх на вибраний період, видавати клієнтам і приймати назад із перевіркою доступності.

## Заплановані функції

- додавання, перегляд, редагування та видалення комп'ютерів;
- збереження даних у `db.json`;
- перевірка правильності введення;
- пошук комп'ютерів за назвою;
- сортування та фільтрування за типом і статусом;
- бронювання комп'ютера на період із перевіркою доступності;
- видача та повернення комп'ютера.

## Технології

- HTML, CSS, JavaScript;
- Live Server: запуск вебсторінок;
- json-server: надання доступу до навчальних даних у `db.json` через запити з JavaScript;
- Git: керування версіями.

## Структура проєкту

```
course-project/

├── js/app.js

├── README.md

```

## Запуск (буде уточнено на етапі тестування)

1. Встановити Node.js.
2. Запустити json-server: `npx json-server db.json`.
3. Відкрити `index.html` через Live Server у VS Code.
