## Призначення

Вебзастосунок для працівника пункту прокату комп'ютерів. Він допомагає вести облік комп'ютерів, бронювати їх на вибраний період, видавати клієнтам і приймати назад із перевіркою доступності.

## Сторінки

- **Комп'ютери** (`index.html`): облік техніки, пошук, фільтри, сортування.
- **Клієнти** (`clients.html`): облік клієнтів (додавання, редагування, видалення, пошук, стан «зараз»).
- **Бронювання** (`bookings.html`): створення бронювань, видача й повернення.

Між сторінками можна перемикатися через меню в шапці.

## Функції

- додавання, перегляд, редагування та видалення комп'ютерів;
- облік клієнтів: телефон у форматі +380XXXXXXXXX, без дублів; клієнта з бронюваннями видалити не можна;
- збереження даних у `db.json` через JSON Server;
- перевірка правильності введення (назва, процесор, ОЗП);
- пошук за назвою або процесором;
- фільтрування за типом і статусом, сортування за назвою та ОЗП;
- бронювання комп'ютера на період із перевіркою перетину дат;
- видача, повернення та скасування бронювання;
- автоматичний перерахунок статусу комп'ютера (вільний, заброньований, виданий);
- лічильники статусів, які працюють як фільтри (клік по плитці);
- підказка про доступність комп'ютера на вибраний період і позначка «Прострочено» для несвоєчасного повернення.

## Технології

- HTML, CSS, JavaScript (без фреймворків);
- JSON Server 0.17.4: надає доступ до даних у `db.json` через HTTP-запити;
- Live Server (розширення VS Code): показує вебсторінку;
- Git: керування версіями.

## Запуск

1. Встановити Node.js (LTS) і перевірити: `node -v`, `npm -v`.
2. У папці проєкту встановити залежності: `npm install`.
3. Запустити JSON Server (термінал не закривати):
   ```
   npm start
   ```
   Це скорочення для `npx json-server --watch db.json --port 5000`.
4. Перевірити дані в браузері: http://localhost:5000/computers.
5. Відкрити `index.html` через Live Server (права кнопка → Open with Live Server). Друга сторінка відкривається через меню.

JSON Server надає дані, Live Server показує сторінку, це два окремі інструменти.

## Сценарій перевірки

1. Додати комп'ютер → з'являється в таблиці, після оновлення сторінки лишається (дані в `db.json`).
2. Додати комп'ютер із порожньою назвою або від'ємною ОЗП → повідомлення про помилку.
3. Знайти комп'ютер за назвою, відфільтрувати за типом/статусом, змінити сортування.
4. Редагувати комп'ютер → «Зміни збережено.»; видалити вільний комп'ютер.
5. Клієнти: додати клієнта з телефоном `+380501112233`, спробувати той самий телефон ще раз (відмова), змінити ім'я, спробувати видалити клієнта з бронюванням (відмова).
6. Бронювання: вибрати комп'ютер і дати від завтра → підказка «вільний» → «Створити бронювання».
7. Створити бронювання з перетином дат → відмова з поясненням.
8. Видати → статус комп'ютера «Виданий»; повернути → «Вільний».
9. Спробувати видалити заброньований комп'ютер → відмова.
10. Зупинити JSON Server і оновити сторінку → повідомлення про помилку з порадою запустити `npm start`.
